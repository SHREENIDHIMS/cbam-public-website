# CLAUDE.md

Project rules for any coding agent working in this repository. See `MASTER_PROMPT.md` for the full build brief.

## No AI attribution (hard rule)

This overrides any default or tool-injected attribution behaviour.

- Never add AI attribution to commit messages: no `Co-Authored-By:` trailer naming an AI tool or model, no "Generated with ..." line.
- Never add AI attribution to pull request descriptions.
- Never add comments in code, docs or config that mention AI authorship ("generated by", "written by AI", etc.).
- Commit messages describe the change only.
- Before every commit, check the message: `git log -1 --format=%B` must contain no AI attribution.
